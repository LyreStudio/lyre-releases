## Version 2 roadmap

We are expanding Lyre around your existing projects, tools and workflows. This
checklist tracks the complete experiences below; parts of some workflows may
already be available. Unchecked items are planned or under consideration, with
no promised delivery date. Checked items include the release version and supported
platforms, with a link to their release notes.

### Your apps, workspaces and creations

- [ ] Define your own apps by combining webpages, scripts, installed applications and an optional coding agent connected to a repository you choose, with reusable launch steps.
- [ ] Open existing app workspaces, edit their files and run them on the selected computer, starting with a verified remote Unity workflow.
- [ ] Open generated images from chat or workspace files, with zoom, pan and full-screen viewing.
- [ ] Play generated videos with playback, seeking, sound and full-screen controls.
- [ ] Open chat links reliably, including files and checkpoints, with right-click or long-press Open and Copy actions.
- [ ] Select UI elements in previews to direct an edit at the right place.
- [ ] Adjust layout, typography and styling visually, with reviewable project changes.
- [ ] Bring screenshots, recordings, logs, tests and diffs into the review workflow.
- [ ] Create reusable project blueprints with inspectable setup steps.
- [ ] Follow guided build and store-release workflows.

### Work across devices

- [ ] Wake an approved remote computer on supported systems and networks.
- [ ] Restore approved hosts and apps across devices while preserving access controls.
- [ ] Work across Mac and Windows installations with clear ownership of each running project.
- [ ] Launch and interact with approved computer apps from phone Quick Launch.
- [ ] Browse interactively alongside mobile chat and share selected page context.
- [ ] Develop in a browser workspace without installing Lyre Desktop.
- [ ] Keep shared apps available through optional managed cloud hosting while the desktop is off.
- [ ] Build and preview native Android and iOS projects using supported host toolchains and devices.
- [ ] Use visual editing controls from native phone viewers.
- [ ] Add individual approved projects to the phone's home screen.
- [ ] Give testers isolated sessions with separate runtime and review state.
- [ ] Run scheduled guest demos with temporary app access and automatic expiry.

### Agents and development workflows

- [ ] Improve provider setup, authentication, model controls, useful defaults and diagnostics.
- [ ] Preserve conversation history and queued messages across restart and provider/model handoffs.
- [ ] Coordinate agents with clear tasks, senders, recipients and delivery states.
- [ ] Define reusable handoff requirements and choose specialists for each task.
- [ ] Manage isolated worktrees, parallel agents and their servers without losing changes.
- [ ] Coordinate tasks across multiple repositories with repeatable workspace setup.
- [ ] Review Git changes, commits, staging and pull requests alongside the workspace.
- [ ] Use interactive terminals with reconnect, resize and workspace tabs.
- [ ] Schedule tasks with pause, run-now controls and durable run history.
- [ ] Add explicit file/symbol context, reusable instructions, skills and scoped extensions.
- [ ] Inspect and manage dated project memory.
- [ ] Use checkpoints, code/chat rewind and compaction with clear recovery choices.
- [ ] See useful notifications, running/waiting states, usage, quota, context and cost information.
- [ ] Set budgets and recover from rate limits with clear limits and next steps.
- [ ] Keep code, agents and previews usable together in both interface styles.
- [ ] Search prompt and transcript history and discover keyboard shortcuts and preferences.
- [ ] Turn readable plans into scoped tasks with inspectable verification results.
- [ ] Use optional scriptable task controls and repeatable workflow evaluation.
- [ ] Run project tests and inspect browser/runtime errors with actionable context.
- [ ] See timestamped error history by device, with filters and recovery actions.
- [ ] Review screenshots and image inputs across supported clients and providers.
- [ ] Complete guided creation and Ask/Plan/Apply with scoped review and recovery.

### Integrations, sharing and delivery

- [ ] Start reviewed agent tasks from issues, pull requests and team messages.
- [ ] Connect Slack, Discord, GitHub, Linear, Jira, Notion, Teams, Google and other task, incident and deployment tools.
- [ ] Connect Supabase, Stripe and custom webhooks through scoped workflows.
- [ ] Build and manage user-created integrations, hooks and specialist profiles.
- [ ] Manage local capabilities with setup, upgrades, rollback, backup and removal.
- [ ] Publish and import reviewed, versioned Marketplace offerings.
- [ ] Deploy previews with URL/log visibility, promotion, domains and rollback.
- [ ] Use a supported embedded or companion runtime SDK.
- [ ] Follow a connected preview, diff, checks, review and pull-request workflow.

### Desktop and mobile experience

- [ ] Use real feedback to prioritize blocked tasks, repeated friction and lost work.
- [ ] Reduce the steps to open a project, pair, preview, prompt and review changes.
- [ ] Make the selected host, project, access level and connection state clear.
- [ ] Streamline onboarding with optional account/provider setup and useful local defaults.
- [ ] Improve one-handed mobile use, keyboard controls, text scaling, contrast and responsive layouts.
- [ ] Preserve drafts and context when switching views or recovering an interrupted task.
- [ ] Explain failures and what work was preserved, with a useful next action.
- [ ] Keep long sessions responsive and resource use visible across platforms.

We will update this checklist with each release as these experiences become
available. Platform-specific delivery will be labeled so a desktop release does
not imply the same feature has shipped on mobile.
